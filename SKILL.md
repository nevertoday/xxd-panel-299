## Panel-specific overlay

The transformed design is one damaged memory-mark, not a clean logo and not a small illustration. Threshold the subject into high-contrast black and white. Use bitmap grain, halftone, ink erosion and a broken silhouette. Recognition stays ambiguous. A scarce residue of color from the photograph may remain. One form only, in a large field, possibly incomplete. Type is a tiny archival index set apart. Reject a full photograph, a commercial brand mark, a UI icon, smooth vector and decorative pattern.

These overlay rules add to `references/soldier-runtime.md`. They never replace the source brief or the family runtime contract.
